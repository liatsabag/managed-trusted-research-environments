Slide 5 • FinOps Engine & Telemetry Two-Tiered Attribution & 15m/24h Pipelines

Two-Tiered FinOps Engine & Proportional Attribution

Every invoiced dollar from Google Cloud Detailed Billing is apportioned with zero drift to researchers using actual usage weights ($W_r$), while system service account spend is captured into Shared Overhead.

Cloud Service Telemetry Metric Weight Allocation Formula
BigQuery SQL total_bytes_billed Cost × (Bytes / ΣBytes)
Vertex AI ai_token_count Cost × (Tokens / ΣTokens)
Compute / Colab notebook_runtime_hours Cost × (Hours / ΣHours)
Cloud Storage storage_bytes Cost × (GCS / ΣGCS)
Zero-Drift Invariant: Σ Total Invoiced ≡ Σ Researcher Spend + Shared Overhead

⚡ Automated Telemetry Pipelines BigQuery DTS

1. 15-Minute Real-Time Curation Loop sp_sync_curated_audit_events

Parses raw audit log sinks, extracts user emails, BigQuery slot-ms, bytes billed, and Colab session bounds (1h-8h cap).

2. Storage Capacity Footprint Sync sync_storage_metrics.py

Hourly worker scans GCS inbound & export buckets (145.77 GB footprint) and attributes byte allocations per researcher folder.

3. 24-Hour Daily & Monthly Rollup sp_aggregate_daily_compute

Compiles unified marts for multi-tenant KPIs, MTD spend forecasts, and historical billing trend reports.

Slide 6 • Autonomous Compliance Vertex AI Gemini 3.7 Flash + Automated IAM Demotion

AI-Powered Ethics Gating & Soft-Downgrade

No manual checklist chasing. Vertex AI Gemini analyzes unstructured legal PDFs (DUAs, Helsinki IRB approvals), and triggers automated policy actions when permits expire.

What is a "Soft-Downgrade"?

Instead of deleting the project or revoking all access, non-compliant rooms are automatically demoted from dataEditor to dataViewer. Researchers can still inspect their existing code and charts, but all write/execute privileges are frozen.

The 2-Step Automated Governance Cycle

1

BigQuery ML Object Table AI Scan

Cloud Workflows triggers sp_scan_governance(). BigQuery queries obj_approval_documents over GCS PDFs, invoking Gemini 3.7 Flash via remote model connection to extract IRB expiration dates into ops_regulatory_checklist.

2

Cloud Run IAM Soft-Downgrade Enforcement

Workflow calls FastAPI /compliance/enforce via authenticated OIDC. For expired rooms, Cloud Identity groups are instantly demoted (roles/bigquery.dataViewer), updating room status to SOFT_DOWNGRADED.

3

Instant Reactivation on DUA Renewal

When legal uploads a renewed IRB/DUA PDF, the next cycle automatically recognizes the new expiration date and restores ACTIVE status with full editor roles.

Slide 7 • Air-Lock Egress Protection Gemini DLP • Small-Cell (k < 5) • DPO Release

Dual-Bucket Air-Lock & Gemini DLP Egress Protection

Researchers cannot directly download data to their laptops. All export candidates must pass through cryptographic quarantine and automated Gemini privacy evaluation.

Dual-Bucket Architecture
📥 Inbound Bucket: Read-Only (Clinical Raw)
📤 Export Bucket: Write-Only Quarantine

3-Stage Egress Verification Pipeline

1. Quarantine & SHA-256 Fingerprinting Airlock Candidate

Files exported from Colab are placed in gs://rr-*-export. System hashes file content with SHA-256 for immutable audit tracking.

2. Gemini AI DLP & Small-Cell Evaluation AI Risk Score

Gemini scans CSVs/reports for small-cell counts ($k < 5$), direct PII/PHI identifiers, patient IDs, and rare genomic re-identification markers. Generates an AI Risk Card (Score: 0-100).

3. Data Privacy Officer (DPO) Release Dual Approval

DPO reviews highlighted risk flags in the Central Portal. Approval signs a time-limited download URL and emits an immutable compliance audit record into BigQuery.
